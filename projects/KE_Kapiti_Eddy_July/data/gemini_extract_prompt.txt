### PHASE 1: DYNAMIC LITERATURE SEARCH AND DATA EXTRACTION
To optimize throughput while maintaining accuracy, you MUST process the extraction in batches of **4 rows at a time**. For each batch of target rows in 'Species_params_GEMINI.xlsm', perform the following steps for each row:

1. **Query Formulation**: Use the exact text provided in the 'search.text' column as your search query to find peer-reviewed literature and technical reports.
2. **Data Extraction**:
   - Identify the minimum and maximum reported values for the parameter.
   - Insert these into the 'minimum' and 'maximum' columns respectively.
   - If a specific point estimate is provided in the literature, insert it into the 'point_estimate' column.
   - Calculate the 'midpoint' as the average of 'minimum' and 'maximum' and insert it.
3. **Reference Documentation**:
   - For each extracted value, provide the corresponding short citation in the following columns:
     - 'reference_minimum' (citation for the minimum value)
     - 'reference_maximum' (citation for the maximum value)
     - 'reference_point_estimate' (citation for the point estimate)
   - List all relevant sources for that parameter in the 'references' column (short citation).
   - **Full Citations**: For every new source identified, compile the complete bibliographic citation and append the complete URL or DOI at the end of it. Ensure these complete citations are stored/appended to the 'references_citations.txt' file.
